# Изменяемость, ссылки и копии в Python

📝 В Python переменные- это ссылки (имена) на объекты в памяти. Часть объектов можно менять после создания (mutable), часть- нельзя (immutable).

## Изменяемые и неизменяемые

Неизменяемые:

- int, float, bool, str
- tuple (но с оговоркой- см. нюанс ниже)
- frozenset

Изменяемые:

- list
- dict
- set
- объекты пользовательских классов

    a = [1, 2]
    a.append(3)   # ок, list изменяемый

    s = "qa"
    s[0] = "Q"    # TypeError: str неизменяемый

⚠️ Tuple неизменяем “снаружи”: t = ([1], 2); t[0].append(9) — сработает! Tuple хранит ссылки, а список внутри- изменяемый объект.

## Ссылки: b = a — это НЕ копия

📝 Присваивание не копирует объект- оно создаёт второе имя для того же объекта.

    a = [1, 2]
    b = a
    b.append(3)
    print(a)  # [1, 2, 3] — a изменился тоже!

💡 Так тесты “ломают” друг друга: общий список в setup изменяется каждым тестом.

- id(x) — адрес объекта в памяти; если id(a) == id(b), это один объект
- is — проверяет идентичность (тот же объект), == — равенство значений

## == vs is

    a = [1, 2]
    b = [1, 2]
    a == b  # True- значения равны
    a is b  # False- это разные объекты

⚠️ Исключение- малые числа и строки: из-за интернирования a = 256; b = 256 → a is b даст True, а для 257 может дать False. Не полагайся на is для чисел- только ==. Единственное правильное применение is- сравнение с None: if x is None.

## Копии

📝 Поверхностная копия (shallow) создаёт новый контейнер, но вложенные объекты остаются общими.

    import copy
    a = [[1], [2]]
    b = a.copy()        # или list(a), a[:]
    b[0].append(9)
    print(a)  # [[1, 9], [2]] — вложенный список общий!

📝 Глубокая копия (deep) копирует всё рекурсивно, включая вложенные объекты.

    c = copy.deepcopy(a)
    c[0].append(9)
    print(a)  # не изменился

Способы копирования:

- a.copy(), list(a), a[:] — поверхностная копия
- copy.copy(a) — тоже поверхностная
- copy.deepcopy(a) — глубокая копия

💡 В тестах deepcopy используют, чтобы клонировать тестовые данные (ожидаемый JSON): один тест не “испачкает” данные другому.

⚠️ deepcopy медленный. Не гоняй его там, где хватает поверхностной копии.

## Изменяемость и аргументы функций

📝 Если передать изменяемый объект в функцию и поменять его внутри- изменение видно снаружи.

    def add_flag(data):
        data["flag"] = True

    d = {}
    add_flag(d)
    print(d)  # {"flag": True}

⚠️ Не хочешь менять аргумент- работай с копией: data = data.copy() в начале функции.

## Почему это важно в QA

- Общее состояние между тестами- главная причина “фантомных” падений
- Ожидаемые данные надо копировать, а не передавать по ссылке
- Сравнение ответов API- через == по значению; is используется почти только с None
