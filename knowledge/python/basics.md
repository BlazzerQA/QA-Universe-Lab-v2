# Python: база для QA

Python — язык с простым синтаксисом. В QA на нём пишут автотесты: API и UI.

## Типы данных

| Тип | Пример | Что это |
|-----|--------|---------|
| int | 42 | целое число |
| str | "test" | строка |
| float | 3.14 | дробное число |
| bool | True | правда / ложь |

## Коллекции

- `list` — упорядоченный изменяемый набор: `[1, 2, 3]`
- `dict` — пары ключ-значение: `{"user": "aigiz"}`
- `tuple` — упорядоченный неизменяемый набор: `(1, 2)`
- `set` — только уникальные элементы: `{1, 2, 3}`

## Пример из практики автотестов

```python
response = {"id": 7, "title": "QA sandbox"}
assert response["id"] == 7
