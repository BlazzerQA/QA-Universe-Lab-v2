# Коллекции данных в Python

📝 В Python четыре базовые коллекции: list, tuple, dict, set. Они отличаются изменяемостью, порядком и уникальностью элементов.

## List (список)

📝 Упорядоченная изменяемая коллекция. Дубликаты разрешены.

    my_list = [1, 2, 3, "qa"]

Основные методы:

- append(x) — добавить элемент в конец
- extend(iterable) — добавить другой список в конец
- insert(i, x) — вставить по индексу i
- remove(x) — удалить первое вхождение x
- pop(i) — удалить и вернуть элемент по индексу i (по умолчанию последний)
- sort() / sorted() — сортировка на месте / возвращает новый список
- reverse() — развернуть порядок
- len(list) — количество элементов
- index(x), count(x) — поиск и подсчет

💡 Пример: копим статусы тестов: statuses = ["passed", "failed"], statuses.append("skipped").

## Tuple (кортеж)

📝 Упорядоченная неизменяемая коллекция. Дубликаты разрешены.

    my_tuple = (1, 2, 3)

- Нельзя добавлять, удалять, менять элементы
- Методы только count(x) и index(x)
- Работает быстрее списка и может быть ключом словаря

💡 Пример: пара “метод + статус”: ("GET", 200).

⚠️ Нюанс: кортеж из одного элемента пишется с запятой: t = (1,), иначе скобки считаются просто скобками вокруг числа.

## Dict (словарь)

📝 Коллекция пар “ключ: значение”. Ключи уникальны, значения могут повторяться. Порядок- по вставке.

    my_dict = {"name": "Буся", "age": 3}

Основные методы:

- dict[key] — получить значение (KeyError, если ключа нет)
- get(key, default) — получить значение без ошибки
- keys(), values(), items() — ключи, значения, пары
- update(other) — слить с другим словарем
- pop(key), del dict[key] — удалить
- setdefault(key, default) — значение или default с записью в словарь

💡 Пример: ответ API в JSON — это dict в Python: response.json()["id"].

## Set (множество)

📝 Неупорядоченная изменяемая коллекция уникальных элементов.

    my_set = {1, 2, 3}

- add(x), discard(x), remove(x)
- union / |, intersection / &, difference / -
- Убирает дубликаты: set([1, 1, 2]) → {1, 2}

💡 Пример: какие браузеры реально покрыты тестами: set(browsers) & {"chrome", "firefox"}.

## Главные отличия

- Изменяемость: list, dict, set — изменяемые; tuple — неизменяемый
- Порядок: list и tuple — упорядочены; dict — по порядку вставки; set — без порядка
- Дубликаты: разрешены в list и tuple; запрещены в set и в ключах dict
- Ключом dict может быть только неизменяемый тип: tuple можно, list нельзя

⚠️ Ловушка изменяемости: a = [1, 2]; b = a; b.append(3) — список a тоже изменится, потому что это ссылка на тот же объект. Копию делай через a.copy() или copy.deepcopy(a).
