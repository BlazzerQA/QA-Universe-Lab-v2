# ООП в Python

📝 ООП (объектно-ориентированное программирование)- способ структурировать код, где данные и функции над ними собраны в объекты.

## Класс и объект

📝 Класс- чертёж/шаблон. Объект (экземпляр)- конкретная реализация класса.

    class User:
        def __init__(self, name, role="qa"):
            self.name = name
            self.role = role

        def greet(self):
            return f"Привет, я {self.name}"

    u = User("Аигиз")   # объект
    u.greet()           # "Привет, я Аигиз"

- __init__- инициализатор: выполняется при создании объекта
- self- ссылка на сам объект; первый параметр каждого метода

⚠️ Забыть self в сигнатуре метода- классическая ошибка новичка: TypeError при вызове.

💡 Page Object в Playwright- это класс: страница в атрибутах, шаги теста в методах.

## Атрибуты класса и экземпляра

    class Config:
        base_url = "http://localhost"   # атрибут класса (общий)

        def __init__(self, token):
            self.token = token          # атрибут экземпляра (свой)

⚠️ Изменяемый атрибут класса общий для всех объектов: поменял у одного- поменялся у всех.

## Наследование

📝 Наследование позволяет создать новый класс на базе существующего, переиспользуя его код.

    class BasePage:
        def __init__(self, page):
            self.page = page

        def open(self, url):
            self.page.goto(url)

    class LoginPage(BasePage):
        def login(self, phone, password):
            self.open("/login")
            self.page.fill("#phone", phone)

- Дочерний класс наследует методы родителя
- super()- вызов метода родителя: super().__init__(page)
- Переопределение- замена метода родителя в дочернем классе

💡 Так строят Page Object: BasePage хранит общие шаги, страницы наследуются от неё.

## Инкапсуляция

📝 Инкапсуляция- сокрытие внутренностей объекта.

- public: name — открытый доступ
- protected: _name — соглашение “внутреннее”, но доступ есть
- private: __name — имя искажается (name mangling), прямой доступ затруднён

⚠️ В Python приватность- соглашение: __ не защищает по-настоящему, просто меняет имя на _Class__name.

## Полиморфизм

📝 Полиморфизм- один и тот же метод ведёт себя по-разному у разных классов.

    class JsonReport:
        def save(self): ...

    class HtmlReport:
        def save(self): ...

    for r in (JsonReport(), HtmlReport()):
        r.save()  # каждый сохраняет по-своему

💡 Код вызывает report.save() и не знает класс объекта- это и есть полиморфизм.

## Магические методы

📝 Магические (dunder) методы определяют поведение объекта с операторами и встроенными функциями.

- __str__ — строка для print()
- __repr__ — строка для отладки
- __eq__ — сравнение через ==
- __len__ — len(obj)

    class TestRun:
        def __init__(self, results):
            self.results = results

        def __len__(self):
            return len(self.results)

        def __str__(self):
            return f"Прогон: {len(self)} тестов"
