# Условия и циклы в Python

📝 Условия и циклы- способ программы принимать решения и повторять действия.

## if / elif / else

    status = 200
    if status == 200:
        print("ok")
    elif status == 404:
        print("not found")
    else:
        print("что-то пошло не так")

⚠️ Сравниваем через ==, присваиваем через =. Перепутать их- классический баг новичка.

⚠️ Отступы 4 пробела- это синтаксис Python, а не просто стиль. Съехал отступ- упал код.

💡 В автотестах так ветвятся по статусу ответа: if response.status_code == 200: ... else: raise AssertionError(...).

## Тернарный оператор

    result = "pass" if status == 200 else "fail"

📝 Одна строка вместо четырёх: значение если условие иначе значение.

## Цикл for

    for i in range(3):
        print(i)  # 0, 1, 2

    for article in articles:
        print(article["title"])

Полезные помощники:

- range(start, stop, step) — последовательность чисел
- enumerate(list) — пары (индекс, значение): for i, x in enumerate(list)
- zip(list1, list2) — параллельный обход двух списков

💡 В тестах enumerate используют, чтобы логировать номер шага: for i, url in enumerate(urls): log(f"Шаг {i}: {url}").

## Цикл while

    n = 0
    while n < 3:
        n += 1

💡 В тестах while живёт в ретраях: повторяем запрос, пока не получим 200 или не кончится лимит попыток.

⚠️ Опасность бесконечного цикла: забываешь менять условие- программа зависает. Всегда проверяй, что условие рано или поздно станет False.

## break / continue / pass

- break — выйти из цикла немедленно
- continue — пропустить текущую итерацию, перейти к следующей
- pass — заглушка, “ничего не делать” (чтобы код не падал по синтаксису)

💡 pass часто ставят в пустых except-блоках и в классах-заглушках: class BasePage: pass.

## else на циклах (фишка собеса!)

📝 Блок else после цикла выполняется, если цикл завершился БЕЗ break.

    for x in [1, 2, 3]:
        if x == 5:
            break
    else:
        print("не нашли")  # выполнится

💡 Кейс из автотестов: ищем элемент в списке страниц; цикл дошёл до конца без break- значит не нашли, в else логируем провал.

🎯 Вопросы с собеса:

- Чем break отличается от continue? (выход из цикла против пропуска итерации)
- Когда выполнится else у цикла? (если цикл не прервался через break)
- Чем range(3) отличается от range(1, 3)? (0-2 против 1-2)
- Что даёт enumerate? (пары индекс-значение за один обход)
- Зачем нужен pass? (заглушка для синтаксиса: пустой блок не разрешён)
