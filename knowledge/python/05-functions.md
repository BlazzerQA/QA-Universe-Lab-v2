# Функции в Python

📝 Функция- именованный блок кода, который можно вызывать много раз. Функции убирают дублирование и разбивают программу на части.

## def и return

    def greet(name):
        return f"Привет, {name}"

    greet("QA")  # "Привет, QA"

- def- объявление функции
- return- возвращает значение и выходит из функции
- Если return нет, функция вернёт None

⚠️ Частая ошибка: ждёшь значение от функции без return- получишь None и падение теста на ровном месте.

💡 В pytest каждый тест- это функция: def test_login(): ...

## Аргументы

    def make_user(name, age=18, role="qa"):
        ...

- Позиционные: передаются по порядку
- Именованные (keyword): передаются по имени: make_user(age=25, name="Буся")
- По умолчанию: заданы в сигнатуре: age=18

⚠️ Изменяемый объект в значении по умолчанию- ловушка: def add(x, lst=[]) — список будет “общим” между вызовами. Правильно: lst=None, а внутри if lst is None: lst = [].

## *args и **kwargs

📝 *args собирает позиционные аргументы в кортеж, **kwargs- именованные в словарь.

    def log(*args, **kwargs):
        print(args)    # (1, 2)
        print(kwargs)  # {"level": "info"}

    log(1, 2, level="info")

💡 Так пишут обёртки и декораторы: def wrapper(*args, **kwargs): return func(*args, **kwargs).

## lambda

📝 lambda- анонимная однострочная функция.

    square = lambda x: x ** 2
    square(3)  # 9

💡 Удобно для сортировки: sorted(users, key=lambda u: u["age"]).

⚠️ В lambda только одно выражение: циклы и многострочная логика туда не помещаются.

## Области видимости

📝 Переменная, созданная внутри функции, локальна: снаружи её не видно.

    def f():
        x = 1  # локальная

    print(x)  # NameError

- global- объявляет, что переменная берётся с уровня модуля (в тестах- плохая практика)
- nonlocal- изменяет переменную внешней функции (используется в замыканиях)

💡 В тестах не используй global: состояние между тестами должно быть изолировано- для этого в pytest есть фикстуры.

## docstring

📝 Первая строка в теле функции- её документация.

    def login(phone, password):
        """Логинит пользователя и возвращает токен."""
        ...

💡 Посмотреть docstring: help(login) или login.__doc__.
