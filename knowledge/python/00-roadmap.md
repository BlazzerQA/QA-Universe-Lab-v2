# Карта курса Python для AQA

📝 Этот раздел- курс с нуля до автотестов. Статьи пронумерованы: читай по порядку, каждая следующая опирается на предыдущую.

## Этап 1. Синтаксис

- 01-basics.md — переменные, типы, приведение
- 02-collections.md — list, tuple, dict, set
- 03-strings.md — строки, срезы, f-строки
- 04-control-flow.md — условия и циклы

## Этап 2. Структура кода

- 05-functions.md — def, return, *args/**kwargs, lambda
- 06-oop.md — классы, self, наследование, полиморфизм
- 07-exceptions.md — try/except, raise, свои исключения

## Этап 3. Уровень выше

- 08-comprehensions-generators.md — включения, yield, итераторы
- 09-decorators.md — замыкания, декораторы, functools.wraps
- 10-mutability-copies.md — ссылки, copy/deepcopy, == vs is
- 11-files-json.md — файлы, with, json, pathlib

## Этап 4. Практика AQA

- 12-venv-pip-pep8.md — виртуальные окружения, pip, стиль
- 13-pytest.md — тесты, фикстуры, parametrize, marks
- 14-requests-api.md — HTTP-запросы к API из Python
