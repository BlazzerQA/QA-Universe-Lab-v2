# Основы Python: переменные, типы, приведение

📝 Python- язык с динамической типизацией: тип есть у значения, а не у переменной.

## Переменные

📝 Переменная- именованное место для хранения значения. Тип не объявляется.

    name = "Буся"
    age = 3
    is_qa = True

- Имя: буквы, цифры, подчеркивание; не может начинаться с цифры
- Стиль: snake_case (my_test_status)
- Можно переприсвоить значение другого типа: x = 1, а потом x = "qa"- Python не запретит

💡 Проверить тип: type(x) → <class 'int'>.

## Базовые типы

📝 int- целые числа. float- числа с плавающей точкой. str- строки. bool- True / False. NoneType- None, “отсутствие значения”.

    x = 10          # int
    pi = 3.14       # float
    s = "qa"        # str
    flag = True     # bool
    nothing = None  # NoneType

## Приведение типов

📝 Приведение типов (кастинг)- преобразование значения из одного типа в другой.

    int("5")       # 5
    float("3.14")  # 3.14
    str(10)        # "10"
    bool(0)        # False
    int(3.9)       # 3- отбрасывание, НЕ округление

⚠️ int("abc") бросит ValueError- строка должна реально содержать число.

⚠️ int(3.9) = 3: дробная часть просто отбрасывается, это не округление.

## Truthy / Falsy

📝 В логическом контексте (if, while) значения бывают “истинные” и “ложные”.

Falsy (ложные):

- 0, 0.0
- "" (пустая строка)
- [], (), {}, set() (пустые коллекции)
- None
