# Включения и генераторы в Python

📝 Включения (comprehensions)- компактный способ создавать коллекции из других коллекций. Генераторы- функции, которые отдают значения лениво, по одному, не храня всё в памяти.

## List comprehension

    numbers = [1, 2, 3, 4]
    squares = [x ** 2 for x in numbers]  # [1, 4, 9, 16]

📝 Синтаксис: [выражение for элемент in итерируемое if условие]

    evens = [x for x in numbers if x % 2 == 0]  # [2, 4]

💡 Пример из QA: вытащить заголовки из ответа API: titles = [a["title"] for a in response.json()].

## Dict comprehension

    users = {"a": 1, "b": 2}
    swapped = {v: k for k, v in users.items()}  # {1: "a", 2: "b"}

💡 Собираем карту статусов: codes = {r["id"]: r["status"] for r in results}.

## Set comprehension

    tags = {t.lower() for t in ["QA", "qa", "AQA"]}  # {"qa", "aqa"}

💡 Уникальные браузеры из отчёта: {r["browser"] for r in runs}.

## Вложенные включения

    matrix = [[1, 2], [3, 4]]
    flat = [x for row in matrix for x in row]  # [1, 2, 3, 4]

⚠️ Читаемость: если включение не влезает в две строки- пиши обычный for. Код читают чаще, чем пишут.

## Генераторы: yield

📝 Генератор- функция, которая отдаёт значения по одному, “по требованию”. Вместо return использует yield.

    def count_up_to(n):
        i = 1
        while i <= n:
            yield i
            i += 1

    gen = count_up_to(3)
    next(gen)  # 1
    next(gen)  # 2

- Генератор помнит состояние между вызовами
- Значения вычисляются лениво (lazy evaluation)
- Память: генератор не хранит весь список

💡 Чтение огромного лога построчно: for line in read_log(path) — генератор отдаёт строки по одной, не грузя файл в RAM.

## Generator expression

📝 То же включение, но в круглых скобках: значения вычисляются лениво.

    squares = (x ** 2 for x in range(1000000))  # не жрёт память
    total = sum(squares)

⚠️ Генератор одноразовый: после исчерпания next() бросит StopIteration. Нужно снова- создавай заново.

## Итераторы: iter и next

📝 Итератор- объект, который отдаёт значения через next() и бросает StopIteration, когда исчерпан.

    it = iter([1, 2, 3])
    next(it)  # 1
    next(it)  # 2
    next(it)  # 3
    next(it)  # StopIteration

- for внутри вызывает iter() и next()
- list, dict, str- итерируемые (iterable), но не итераторы; iter() делает из них итератор

## Когда что использовать

- List comprehension- когда нужен весь результат сразу и он небольшой
- Генератор- когда данных много или они бесконечные, либо нужны не все
- Обычный for- когда логика сложная и включение становится нечитаемым
