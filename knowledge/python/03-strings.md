# Строки в Python

📝 Строка (str)- неизменяемая упорядоченная последовательность символов. Пишется в одинарных, двойных или тройных кавычках.

    s = "qa"
    s2 = 'qa'
    s3 = """многострочная
    строка"""

## Срезы

📝 Срез- часть строки по индексам. Индексы начинаются с 0, отрицательные- с конца.

    s = "playwright"
    s[0]      # "p"
    s[-1]     # "t"
    s[0:4]    # "play"- от 0 до 4 не включительно
    s[:4]     # "play"- с начала
    s[4:]     # "wright"- до конца
    s[::2]    # "pwrg"- шаг 2
    s[::-1]   # "thgirwalp"- переворот строки

## f-строки

📝 f-строка- интерполяция: переменные и выражения подставляются прямо в строку.

    name = "Буся"
    age = 3
    print(f"Коту {name} уже {age} года")

💡 В автотестах f-строками собирают URL и сообщения об ошибках: f"http://localhost/notes/{article_id}".

## Основные методы

- upper() / lower() — регистр
- strip() — убрать пробелы по краям (lstrip, rstrip- с одной стороны)
- replace(old, new) — замена подстроки
- split(sep) — разбить строку в список по разделителю
- join(list) — склеить список в строку
- find(sub) / index(sub) — поиск подстроки (find вернёт -1, index бросит ValueError)
- startswith(prefix) / endswith(suffix) — проверка начала/конца
- count(sub) — количество вхождений
- isdigit() / isalpha() — проверка состава символов

💡 Пример из QA-практики: проверить, что в ошибке есть нужный текст: assert "неверный пароль" in error_text.lower().

## Важные нюансы

⚠️ Строка неизменяема: s[0] = "Q" не сработает- нужно создавать новую строку.

⚠️ Сравнивай строки через == (по значению), а не через is (по ссылке).

⚠️ \n и \t- спецсимволы. Если не хочешь, чтобы их интерпретировали (пути в Windows), ставь r перед кавычками: r"C:\new\test".
