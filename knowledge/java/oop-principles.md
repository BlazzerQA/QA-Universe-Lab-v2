# Принципы объекто ориентированного программирования

(все написано без использования ИИ , а своими словами , чтобы на собесе ответить можно)

Порядка обязательного нету можно называть в любом

## 1) Инкапсуляция

это принцип ООП , при котором данные(свойства,поля класса) скрываются от прямого доступа , а взаимодействие с ними происходит
за счет специальных методов = это гарантирует контроль над данными и их
защиту от неправильного использования.

Реализуется данный принцип за счет модификаторов доступа (в java это - `public`, `private`, `protected`, `default`)

- `public` - публичный доступ-доступен со всех мест (доступен имеется ввиду метод или поле класса, а поле класса - это переменная с типом данных)
- `private` - приватный доступ- доступен только внутри класса
- `protected` - доступен в классах наследниках, внутри класса и в классах внутри пакета
- `default` - доступен только внутри пакета

Пример:Например, мы внутри класса создадим переменную `private String password;` (в других классах теперь нельзя обратиться к этой переменной напрямую
для этого мы создадим спец метод

```java
public void changePassword(String password) {
    this.password = password; // условно и уже через этот метод будем обращаться к переменной password)
}
```

Это и есть инкапсуляция

## 2) Полиморфизм

(от слова много форм) - это принцип ООП, который позволяет работать с объектами разных классов через общий тип(например, родительский класс,
или интерфейс), при этом один и тот же метод может выполняться по-разному в зависимости от конкретного объекта

Реализуется данный принцип за счет переопределения методов в разных классах , т.е у нас есть один интерфейс или базовый класс с описанием методов, а разные классы
будут реализовывать эти методы по-своему

Банальный пример:есть класс `Animal` c методом `makeSound()` и есть классы наследники(дочерние классы от `Animal`) такие как `Cat` и `Dog`
так вот `makeSound()` в каждом классе будет свой у одного это ГАв у другого Мяу = Общий метод , но разная реализация

Важный момент, что есть два вида полиморфизма - статический и динамический

- Статический полиморфизм реализуется за счет перегрузки методов (overloading) - это когда в одном классе есть несколько методов с одинаковым
названием, но разными параметрами
- Динамический полиморфизм реализуется за счет переопределения метода(overriding)

## 3) Наследование

это принцип ООП, при котором один класс может взаимствовать поведение и свойства другого класса, т.е. дочерний класс
получает все методы и поля родителя(но поля и методы с модификатором `private` недоступны напрямую), а сам может добавлять свои собственные или переопределять существующие(полиморфизм)

Реализуется засчет ключевого слова `extends` (перевод "расширить")

Пример:

```java
class Cat extends Animal { }
```

## 4) Абстракция

это принцип ООП , который гласит так "Скрываем сложные детали реализации и показываем только важные характерстики"

Абстракция может быть реализована разными средствами в Java , например, интерфейсами,абстрактными классами или обычным классом через сокрытие деталей реализации.

Пример: Я создал абстрактный класс `BaseTest` , где например описываю общие шаги тестов, настройку окружения, подлючение алюр отчетов
И потом создаю тесты , которые будут наследоваться от `BaseTest` , так я скрою общую логику , а тесты будут фокусироваться только на специфике и им не важно
знать что происходит внутри `BaseTest` (образно говоря)
