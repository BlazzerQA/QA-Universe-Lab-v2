# Статус коды HTTP

📝 Самые популярные — 200, 201, 400, 401, 402, 403, 404, 504.

## 1xx (Информационные)

- 100 Continue (клиент получил 1-ую часть запроса, продолжай)
- 102 Processing (ответ пока в процессе)

## 2xx (Успешные)

- 200 OK (запрос обработан, ответ получен)
- 201 Created (новый ресурс создан)
- 204 No Content (запрос обработан, но в ответе пусто)

## 3xx (Перенаправление)

- 301 Moved Permanently (ресурс был перемещен)
- 302 Found (ресурс доступен по другому URL)
- 304 Not Modified (ресурс не изменен, используй кеш)

## 4xx (Ошибка клиента)

- 400 Bad Request (неправильный запрос)
- 401 Unauthorized (требуется аутентификация)
- 403 Forbidden (нет разрешения к данному ресурсу)
- 404 Not Found (сервер не может найти этот ресурс)
- 429 Too Many Requests (слишком много запросов “в секунду”)

## 5xx (Ошибка сервера)

- 500 Internal Server Error (непредвиденная ошибка на сервере)
- 502 Bad Gateway (сервер-прокси получил недействительный ответ от вышестоящего сервера)
- 503 Service Unavailable (сервер недоступен)
- 504 Gateway Timeout (сервер-прокси не получил своевременный ответ от вышестоящего сервера)

⚠️ На собесе любят спрашивать: “чем 401 отличается от 403?” Ответ: 401 — ты вообще не представился системе (нет аутентификации), 403 — ты представился, но прав на этот ресурс у тебя нет (нет авторизации). Вспоминай статью про три “И”.
