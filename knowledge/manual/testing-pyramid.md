# Пирамида тестирования / Уровни тестирования

📝 Пирамида тестирования / Уровни тестирования- группировка тестов по уровню детализации их назначению.

## Пирамида

                /\
               /  \
              / E2E \
             /-------\
            / System  \
           /-----------\
          / Integration \
         /---------------\
        / Module (unit)   \
       /___________________\

    Вверх по пирамиде: важность и стоимость растут, скорость падает
    Вниз по пирамиде: количество тестов и их скорость растут

## Приемочное

📝 Приемочное- проверяет соответствие системы потребностям и требованиям пользователя.

## Системное

📝 Системное- проверка функциональных и нефункциональных требований.

## Интеграционное

📝 Интеграционное- проверка корректности взаимодействия нескольких модулей.

💡 Пример: Корректно определяется местоположение и вводится в поле “место назначения” на другом экране.

## Модульное (компонентное/ unit)

📝 Модульное (компонентное/ unit)- тестирование чего-то одного- функций, классов, модулей. Выполняется программистами.

💡 Пример: В яндекс go корректно определяется местоположение.
