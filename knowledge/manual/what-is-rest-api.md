# Что такое REST API?

📝 REST- это архитектурный стиль (список рекомендаций).

📝 REST API- это конкретная реализация этого стиля в виде программного интерфейса.

Не все API, называющие себя "REST API", обязательно полностью соответствуют всем принципам REST, но они используют ключевые принципы и HTTP-методы.

## RESTful

📝 Быть RESTful означает, что API следует архитектурным принципам и ограничениям REST.

## Принципы REST

📝 REST определен не так строго, как SOAP. RESTful-архитектура должна соответствовать шести архитектурным ограничениям:

- Единый интерфейс — позволяющий единообразное взаимодействие с сервером вне зависимости от типа устройства или приложения

- Отсутствие состояния — необходимое состояние обработки запроса содержится в самом запросе без того, чтобы сервер хранил какие-либо относящиеся к сессии данные

- Кэширование

- Клиент-серверная архитектура — позволяет независимое развитие двух сторон

- Многоуровневая система приложения

- Возможность для сервера обеспечивать исполняемый код на клиенте

💡 В проекте друга: GET /api/notes отдаёт список статей — это REST-подобно. Единый интерфейс (URL + HTTP-методы), отсутствие состояния (сервер не помнит, кто спрашивал прошлый раз), клиент-сервер (фронт и бэк развиваются отдельно).
