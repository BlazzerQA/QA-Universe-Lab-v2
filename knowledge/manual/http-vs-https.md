# HTTP vs HTTPS?

📝 HyperText Transfer Protocol- протокол передачи гипертекста. Он определяет, как информация передается между веб-сайтом и браузером. Это своего рода язык, на котором они “разговаривают” друг с другом.

Зашли на сайт → браузер отправил HTTP-запрос на сервер → сервер отправляет ответ в виде веб-страницы → браузер получает этот ответ и отображает веб страницу.

## HTTP (HyperText Transfer Protocol)

- Передает данные в открытом виде, доступном для перехвата
- Использует порт 80

## HTTPS (Hyper Text Transfer Protocol Secure)

- Шифрует данные, обеспечивая безопасную передачу (SSL!!!)
- Использует порт 443
