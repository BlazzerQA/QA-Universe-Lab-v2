# HTTP методы (GET POST PUT DELETE PATCH)

📝 Основные- GET, POST, DELETE, PUT, PATCH, OPTIONS.

## Основные

| Метод | Операция | Используется Body? | Безопасный? | Идемпотентный? | Кешируемый? |
|-------|----------|--------------------|-------------|----------------|-------------|
| GET | Получение данных | Нет | Да | Да | Да |
| POST | Отправка данных | Да | Нет | Нет | Нет |
| PUT | Изменение данных | Да | Нет | Да | Нет |
| DELETE | Удаление данных | Да | Нет | Да | Нет |
| PATCH | Частичное изменение данных | Да | Нет | Нет | Нет |

## Редкие

| Метод | Операция | Используется Body? | Безопасный? | Идемпотентный? | Кешируемый? |
|-------|----------|--------------------|-------------|----------------|-------------|
| OPTIONS | Вернет список используемых методов на сервере | Да | Да | Да | Нет |
| HEAD | Аналог GET, но в ответе не использует тело | Нет | Да | Да | Да |
| TRACE | Для диагностики, чтобы посмотреть всю цепочку звеньев | Да | Да | Да | Нет |
| CONNECT | Установка “туннеля” к серверу | Да | Да | Да | Нет |
