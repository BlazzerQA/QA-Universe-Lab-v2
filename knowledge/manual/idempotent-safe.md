# Идемпотентный и безопасный запрос

📝 Идемпотентный запрос- такой запрос, при котором его повторное выполнение не меняет результат первого выполнения (например, GET запрос).

📝 Идемпотентный запрос- это запрос, эффект которого от многократного выполнения равен эффекту от однократного выполнения.

📝 Идемпотентная операция всегда приводит к одному и тому же результату, независимо от того, сколько раз она выполнялась.

📝 Идемпотентные методы- это методы, которые либо не изменяют состояние в базе данных, либо изменяют состояние только при первом запросе. В случае повторной отправки идентичного запроса, состояние в базе данных не изменяется.

📝 Безопасный запрос- это запрос, который не изменяет состояния ресурса на сервере.

📝 Безопасный запрос- это запрос, который не изменяет базу данных.

📝 Безопасные методы- это методы, которые не изменяют состояние в базе данных (read only методы). Примечательно, что все безопасные методы также являются идемпотентными.

## Списки методов

Идемпотентные запросы:

- GET, PUT, DELETE, OPTIONS, HEAD, TRACE, CONNECT

Не идемпотентные запросы:

- POST, PATCH

Безопасные запросы:

- GET, OPTIONS, HEAD, TRACE, CONNECT

Не безопасные запросы:

- POST, PUT, DELETE, PATCH

💡 Мнемоника для собеса: “безопасный = только читает; идемпотентный = повтор не меняет результат”. Все безопасные методы автоматически идемпотентны, но не наоборот: PUT идемпотентный, но не безопасный (он же меняет данные).
