# Отправка данных на сервер через GET

📝 Да, через параметры в URL, а не через body.

https://example.com/api?param1=value1&param2=value2 — данные передаются в виде ключ-значение после знака ? в URL.

1. Размер данных, передаваемых в GET-запросе, ограничен длиной URL-адреса (обычно до 2048 символов).

2. GET-запросы должны быть безопасными и идемпотентными, они не должны изменять состояние сервера.

3. Данные, передаваемые в GET-запросе, могут быть видны в адресной строке браузера, поэтому GET не рекомендуется использовать для передачи конфиденциальной информации.
