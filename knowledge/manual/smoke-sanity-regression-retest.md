# Smoke, Sanity, Regression, Re-testing

📝 Все эти тесты проводятся после каких-то изменений (добавление новой фичи, новый билд приложения, миграция на другую ОС или БД).

## Smoke (дымовое)

📝 Smoke (дымовое)- основная проверка над новой фичей с целью подтверждения того, что ПО стартует и выполняет основные для бизнеса функции.

💡 Пример: делаем смок формы регистрации → юзер должен иметь возможность зарегистрироваться.

## Sanity (санитарное)

📝 Sanity (санитарное)- углубленная проверка какой-то функциональности, локальное тестирование 1 фичи, которую разработали.

💡 Smoke- смогли зарегистрироваться, Sanity- проверка поля ввода пароля.

## Regression (регрессионное)

📝 Regression (регрессионное)- тестирование уже проверенной ранее функциональности после каких-то изменений. Проводится для уверенности в том, что изменения не повлияли на другие модули ПО и не вызывали новых багов.

## Re-test (повторное)

📝 Re-test (повторное)- проверка исправления бага (тестирование, во время которого исполняются тестовые сценарии, выявившие ошибки во время последнего запуска, для подтверждения успешности исправления этих ошибок).
