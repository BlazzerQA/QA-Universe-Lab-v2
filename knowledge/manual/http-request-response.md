# Структура HTTP запроса и ответа

## HTTP Request (запрос)

- Тип — GET, POST, PUT, DELETE, PATCH и тд
- URL — https://www.google.com/
- Headers — Content-Type, User-Agent, Auth, Cookie
- Body

## HTTP Response (ответ)

- Статус — 200, 201, 400, 401, 403
- Headers — Content-Type, Server, Set-Coockie, Date
- Body
- Time
- Size
