# Клиент-серверная архитектура

📝 Клиент-серверная архитектура — взаимодействие между клиентом, сервером и базой данных.

Отправляем HTTP Request (запрос) на сервер → он передает это в БД → БД отправляет серверу данные → сервер отправляет нам HTTP Response (ответ).

💡 Еще можно рассказать про:

- Балансировщики нагрузки, которые распределяют нагрузку между серверами
- Если у нас монолитная архитектура, то идет запрос к одному серверу, а если микросервисная, то запросы идут к разным серверам

💡 В проекте друга: клиент — браузер с сайтом (nginx), сервер — Spring Boot бэкенд в Docker, база данных — SQLite (таблица users). Когда ты открываешь /notes, браузер шлёт запрос бэкенду, тот читает статьи и возвращает ответ.
