# Баг-репорт

📝 Баг-репорт- отчет об ошибке, который заводится в баг-трекинговой системе.

🟣 - автоматически выставляются, 🟢 - основные, 🟤 - дополнительные.

## Поля баг-репорта

🟣 Дата создания — выставляется автоматически

🟣 Автор — выставляется автоматически

🟣 ID — выставляется автоматически

🟢 Summary (заголовок) — “Что? Где? При каких условиях?”

🟢 Description (описание) — описание в свободном формате

🟢 Steps to reproduce (шаги воспроизведения) — глаголы в инфинитиве, например: 1. Открыть сайт... 2. Перейти в...

🟢 Actual result (фактический результат) — словами + можно скрин или скринкаст

🟢 Expected result (ожидаемый результат) — словами / скрином / ссылкой на макет

🟢 Environment (окружение) — Prod/Stage? Версия билда. Операционная система (Windows, Mac, IOS и тд). Браузер и его версия

🟢 Priority (приоритет) — сюда пишем Severity (серьезность) ошибки: Blocker, Critical, Major, Minor, Trivial

🟤 Assignee to (назначен на) — имя разработчика, выставляем, скорее всего, не мы

🟤 Проект — проект на котором баг был найден

🟤 Компонент приложения — в какой именно части проекта он найден?

🟤 Label (метки) — тэги для бага, чтобы быстро его находить

🟤 Ручка (чаще для багрепорта на бекенд) — cUrl запроса

🟤 Test devices (тестовые устройства) — Iphone XR ios 15 (экран...), Android (какой-нибудь версии), Macbook (какой-нибудь версии)

🟤 Analytics (аналитика) — ссылка на яндекс.метрику с указанием количества пользователей, которых касается эта проблема

🟤 Documentation (документация) — ссылка на документацию по фиче

🟤 Logs (логи) — ссылка на логи из Kibana или Sentry

🟤 Followers (подписчики) — кто получит уведомление об этом баге. Например, boss, manager

🟤 Link tasks/bugs (ссылка на задание или баг) — подвязка других задач/багов к текущему

⚠️ Обычно в баг-репорте нет поля Severity. Обычно в баг-репорте есть поле Priority и туда мы пишем Severity.

## Пример баг-репорта

💡 Ошибка: Всплывающее окно не пропадает, пока не изменяется дата.

Тип: Баг

Приоритет: Низкий

Статус: Блокирующий

Автор: Василий Васильков

Серьезность: Высокая

Шаги воспроизведения:

1. Выбрать любое блюдо
2. Перейти в корзину
3. Выбрать следующую после крайней дату доставки в меню (пример: меню с 8 по 14 ноября, выбрать 15 ноября)
4. После того, как появилось всплывающее окно “Доставка до 14.11”, нажать кнопку “изменение даты”
5. Посмотреть на всплывающее окно

Ожидаемый результат: Всплывающее окно “Доставка до 14.11” не появляется

Фактический результат: Всплывающее окно остается до тех пор, пока дата не изменится на подходящую.Ы
