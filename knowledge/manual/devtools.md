# DevTools

## Вкладка Network

📝 Network- вкладка DevTools для анализа сетевого трафика и запросов к серверу.

Там можно увидеть:

- Все HTTP запросы, отправленные со страницы (URL, время загрузки, размер данных и другое)
- Подробную инфу о каждом запросе (метод, статус, Headers, параметры, ответ сервера (Response), время обработки, Payload)
- Возможность фильтрации по разным критериям
- Визуализацию загрузки страницы по времени
- Информацию о кэшировании, сжатии и прочее

📝 Вкладка Network является ключевым инструментом для отладки и оптимизации сетевых запросов, а также для понимания производительности веб-приложения.

💡 Практика: открой http://localhost/notes, нажми F12 → Network → обнови страницу. Увидишь GET-запрос к /api/notes со статусом 200 — это ровно то, про что пишет дока.

## Функции DevTools

- Инспектор элементов (Element Inspector): просмотр и редактирование структуры HTML-кода страницы; изучение стилей CSS, применяемых к элементам
- Вкладка "Сеть" (Network): анализ всех сетевых запросов, выполненных страницей; изучение времени загрузки, размера данных и других характеристик запросов
- Вкладка "Источники" (Sources): просмотр и отладка JavaScript-кода страницы; установка breakpoints и пошаговое выполнение кода
- Вкладка "Консоль" (Console): просмотр и фильтрация журнала ошибок и предупреждений; выполнение JavaScript-кода в интерактивном режиме
- Вкладка "Производительность" (Performance): профилирование и анализ производительности страницы; визуализация и поиск узких мест в загрузке ресурсов
- Инструменты для отладки мобильных устройств: эмуляция различных устройств и размеров окна браузера; симуляция медленных сетевых условий
- Вкладка "Приложение" (Application): просмотр и управление cookies, localStorage, IndexedDB и другими веб-хранилищами; проверка манифестов веб-приложений и сервис-воркеров
- Вкладка "Безопасность" (Security): проверка и отладка настроек безопасности веб-приложения; информация о соединении, сертификатах и безопасном протоколе
