# Тест кейс vs чек лист

📝 Основной атрибут тест-кейса- ожидаемый результат + шаги для воспроизведения.

В тест-кейсе по шагам описываем путь проверки с указанием условий и ожидаемого результата, а в чеклисте мы просто приводим перечень необходимых проверок без шагов и пояснений.

Тест-кейсы более надежны, так как в них расписано все максимально подробно → низкая вероятность разночтения. Также тест-кейсы помогают другим тестировщикам быстрее влиться в проект (пришел новенький на проект, кто-то заболел и тп). НО их составление занимает гораздо больше времени.

## Тест-кейс

- Описываем предусловия + шаги для воспроизведения + ожидаемый результат
- Низкая вероятность разночтения
- Другие тестировщики быстрее вливаются в проект
- Из-за формализации занимают много времени

## Чек-лист

- Краткий перечень необходимых проверок
- Есть вероятность разночтения
- Другим тестировщикам сложнее влиться в проект
- Составление занимает меньше времени

## Когда используется?

- Тест-кейс: в больших и сложных проектах
- Чек-лист: на начальной стадии проектов, когда мало времени

Пишем чек-лист, а по нему пишем тест-кейс.
