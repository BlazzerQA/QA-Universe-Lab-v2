# Что такое API?

📝 Application Programming Interface — программный интерфейс приложения — набор правил и протоколов, которые позволяют программам обмениваться данными и взаимодействовать друг с другом.

📝 API — интерфейс (способ) взаимодействия с бэкэндом (сервера). Реализован в виде HTTP методов, с помощью которых можно отправить/ получить данные с бэкэнда (сервера).

📝 API — интерфейс, часто реализованный в виде HTTP методов, с помощью которого может взаимодействовать клиент и сервер (или сервер и сервер).

💡 Например, когда вы используете приложение, которое показывает вам погоду, это приложение использует API для получения данных о погоде от поставщика этих данных. API позволяет приложению запросить эту информацию и получить ее в удобном для себя формате.

API можно вызывать напрямую:

- Система вызывает функции внутри себя
- Система вызывает метод другой системы
- Человек вызывает метод
- Автотесты дергают методы

API можно вызвать косвенно:

- Пользователь работает с GUI
