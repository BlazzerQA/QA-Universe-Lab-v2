# Протоколы, кроме HTTP

1. FTP (File Transfer Protocol)- протокол для передачи файлов между компьютерами. Используется для загрузки и выгрузки файлов на сервера.

💡 Например: Adobe использует FTP-серверы для распространения установочных файлов для своих продуктов (PhotoShop).

2. WebSocket- протокол, который обеспечивает постоянное соединение в реальном времени между клиентом и сервером.

💡 Например: Discord (одновременно говорим), Twitter (обновление ленты), Google Docs (работа над документом в реальном времени).

3. SMTP (Simple Mail Transfer Protocol)- протокол для пересылки электронной почты между почтовыми серверами.

💡 Например: Gmail, Outlook, Yahoo Mail.

4. POP3 (Post Office Protocol)- протокол для получения и хранения электронной почты на клиентских устройствах.

💡 Например: почтовый клиент Mozilla Thunderbird.
